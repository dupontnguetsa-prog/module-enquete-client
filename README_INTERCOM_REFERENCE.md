# Référence fonctionnelle — Outbound

La conception fonctionnelle de cette version s'inspire des concepts publics décrits dans la documentation Outbound d'Intercom : règles de message (quand/comment/à qui), audiences dynamiques ou fixes, événements comme déclencheurs/filtres, planification, surveys, partage et analyse.

L'interface, les textes, le style et le code Afriland sont originaux et ne copient pas l'interface Intercom.
